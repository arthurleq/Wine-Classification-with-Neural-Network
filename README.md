# Wine Classification with a Multilayer Perceptron (PyTorch)

This project demonstrates the classification of wine origins using a Multilayer Perceptron (MLP) implemented with PyTorch.

Was created with the help of https://github.com/zankerx

The notebook explores the complete machine learning workflow:
- data loading,
- preprocessing,
- model creation,
- training,
- evaluation,
- hyperparameter exploration,
- and visualization of the learning process.

The dataset used is the well-known Wine dataset from the UCI Machine Learning Repository.
